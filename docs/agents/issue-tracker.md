# Issue Tracker

**Type:** GitHub Issues

**Repository:** `pvloi03/phuxuan-parking-system`

**CLI:** Uses `gh` command

---

## Workflow

Matt Pocock engineering skills write and read issues using the GitHub CLI:

- **Create issues:** `gh issue create --title "..." --body "..." --label "..."`
- **Read issues:** `gh issue list --label "..." --state "open"`
- **Update issues:** `gh issue close <number>`, `gh issue edit <number> --add-label "..."`

---

## PRs as Request Surface

**Status:** Off

External PRs are not surfaced in the triage queue.

## Commands

Skills that use this tracker:
- `/grill-with-docs` → creates issues for unresolved questions
- `/triage` → reads incoming bug reports and feature requests
- `/to-tickets` → creates agent-ready implementation issues
- `/wayfinder` → creates decision tickets
